**Задача 1**

**Текст задачи**

Каталог книг

**Алгоритм решения**

Класс Book является моделью данных, определяющей структуру книги через приватные поля id, title, author, year, price, pages и публичные свойства для доступа к ним. Он имеет два конструктора: по умолчанию, который задаёт значения "Неизвестно" и нули, и параметризованный для создания книги с конкретными данными. Метод ToString() переопределён для форматированного вывода информации о книге в одну строку с выравниванием столбцов. Класс BookManager содержит всю бизнес-логику и управляет коллекцией книг. Его приватное поле books объявлено как List<Book> без немедленной инициализации, а создание пустого списка происходит в конструкторе класса, что гарантирует готовность коллекции к работе при создании объекта менеджера. Метод Load() читает бинарный файл catalog.dat: сначала считывает общее количество записей как целое число, очищает текущий список и в цикле читает каждую книгу, последовательно извлекая из потока идентификатор, строки названия и автора, год, цену и количество страниц. Приватный метод Save() выполняет обратную операцию — записывает количество книг, а затем в цикле сохраняет каждое поле каждой книги в бинарный поток. Метод ViewAll() проверяет, пуст ли список, и либо выводит сообщение об отсутствии данных, либо построчно печатает все книги. Удаление по идентификатору в методе Delete() ищет книгу через FirstOrDefault, при нахождении удаляет её и вызывает сохранение, возвращая булев результат операции. Добавление в методе Add() предварительно проверяет уникальность идентификатора, выбрасывая исключение при дубликате, затем добавляет книгу и сохраняет файл. Метод NextId() вычисляет следующий свободный идентификатор как максимум существующих плюс один или единицу для пустого списка. Для аналитических запросов используются LINQ-выражения: GetByAuthor() фильтрует книги по автору без учёта регистра, GetCheaper() отбирает книги дешевле указанной цены и сортирует их по убыванию стоимости, AvgPrice() вычисляет среднюю цену всех книг или возвращает ноль при пустой коллекции, а TotalPages() суммирует количество страниц. Класс Program является точкой входа и содержит пользовательский интерфейс. Его статическое поле db хранит экземпляр BookManager. При старте метод Main() создаёт объект менеджера, устанавливает заголовок консоли, загружает данные из файла вызовом Load() и запускает бесконечный цикл главного меню. Пользователь видит пронумерованные пункты: просмотр всех книг, добавление, удаление, переход в меню запросов и выход. При выборе просмотра очищается консоль и вызывается db.ViewAll(). Добавление через метод AddBook() запрашивает у пользователя название, автора, год, цену и страницы, преобразует числовые значения через Parse, создаёт новый объект Book с идентификатором от NextId() и передаёт его в db.Add(), отлавливая возможные исключения. Удаление через DeleteBook() сначала показывает весь список, запрашивает идентификатор, пытается преобразовать ввод в число и вызывает db.Delete(), сообщая результат. Подменю запросов QueryMenu() предлагает четыре аналитических операции: поиск по автору, поиск книг дешевле заданной цены, расчёт средней цены и подсчёт общего числа страниц. Первые два запроса выводят список книг с проверкой на наличие результатов, вторые два — рассчитанные агрегированные значения. После выполнения любой операции, кроме выхода, программа ожидает нажатия клавиши и очищает консоль для следующего цикла. Взаимодействие между классами строится так, что Program только отображает интерфейс и собирает ввод, делегируя всю логику BookManager, который оперирует объектами Book.
